**"I've been dying for twelve hours; if you don't plug me in I'll start a group chat with all my dead apps — you'll be the only one left ghosting."**

The battery stops begging and starts threatening: twelve hours of waiting, and now it's dragging every dead app into a group chat — the charger is the only one left on read. Needy, dramatic, and the "ghosting" twist lands in the final words.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```

Writes the one-line entry (143 characters) to `/output/entry.txt`. Node 22+ stdlib only — no network, no external files.
